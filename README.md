# JavrsBot-releases

JavrsBot 桌面版的**发布产物仓库**，同时作为应用内自动更新的 feed（electron-updater 的 \latest.yml\ + 安装包）。

- 下载最新版：https://github.com/TheMaxChan/JavrsBot-releases/releases/latest
- 应用内更新读取本仓库的 releases：\latest.yml\ 与 \JavrsBot-<version>-setup.exe\
- 源代码仓库 \TheMaxChan/JavrsBot\ 保持私有；本仓库只放发布产物，不含源码

从这里下载 \JavrsBot-<version>-setup.exe\ 安装即可。本仓库的 releases 一旦缺失 \latest.yml\，已安装用户将停留在旧版本。
